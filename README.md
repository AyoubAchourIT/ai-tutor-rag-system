# Document-Grounded AI Tutor

This project explores the design of a document-grounded AI tutor system
based on a Retrieval-Augmented Generation (RAG) architecture.

The objective is to assist developers in Python and machine learning tasks
by combining:

- Local LLM inference (Ollama - llama2)
- Embedding-based retrieval (nomic-embed-text)
- Vector database (Chroma)
- Structured prompting
- Neural network experimentation (TensorFlow/Keras)

---

## Architecture Overview

1. Document ingestion (PDF, text, HTML)
2. Text splitting and embedding
3. Vector storage with Chroma
4. Retrieval-based augmentation
5. LLM response generation
6. Neural network learning component

---

## Key Concepts Explored

- Retrieval-Augmented Generation (RAG)
- Local LLM deployment
- Prompt engineering
- Embedding models
- Performance-aware parameter tuning
- Neural network training workflow

---

## Purpose

This repository focuses on system design and structured experimentation
rather than productization.

It reflects an interest in combining:

- Machine learning engineering
- Applied mathematics
- LLM systems
- Reproducible experimentation
